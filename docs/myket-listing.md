# راهنمای انتشار اولیه در مایکت

این راهنما برای نسخهٔ اولیه‌ای است که اعتبار رایگان را ارائه می‌کند و خرید درون‌برنامه‌ای هنوز فعال نیست. پس از ساخت محصولات مایکت، کلیدهای خرید باید جداگانه به CI و Cloudflare اضافه شوند.

## اطلاعات پایه

| فیلد مایکت | مقدار پیشنهادی |
|---|---|
| عنوان فارسی | مکانیک هوشمند |
| عنوان انگلیسی | Smart Mechanic AI |
| دسته‌بندی | خودرو و وسایل نقلیه (یا نزدیک‌ترین گزینه به Auto & Vehicles) |
| نوع انتشار | رایگان |
| زبان اصلی | فارسی |
| محدوده سنی | همه سنین |
| نام توسعه‌دهنده | نام حقیقی/حقوقی ثبت‌شدهٔ شما در پنل مایکت |
| ایمیل پشتیبانی | ایمیلی که پاسخ‌گویی آن را تضمین می‌کنید |

## توضیح کوتاه

عیب‌یابی اولیه خودرو با متن، عکس، صدای موتور و ویدئو؛ با راهنمای فارسی و هشدارهای ایمنی.

## توضیح کامل فارسی

مکانیک هوشمند به شما کمک می‌کند نشانه‌های اولیهٔ مشکل خودرو را بهتر بررسی کنید. مشکل را بنویسید، از قطعه عکس بفرستید یا صدای موتور و یک ویدئوی کوتاه ثبت کنید تا یک گزارش ساختاریافته و فارسی دریافت کنید.

امکانات برنامه:

- ثبت و مدیریت خودروهای شما
- بررسی علائم با متن
- تحلیل عکس قطعات و چراغ‌های هشدار
- تحلیل صدای موتور
- تحلیل ویدئوی کوتاه
- نمایش نتیجه، شدت احتمالی مشکل و پیشنهاد گام بعدی
- نگه‌داری سوابق بررسی‌ها روی دستگاه

توجه: نتایج برنامه فقط راهنمای اولیه هستند و جایگزین بررسی مکانیک متخصص نیستند. در موارد ایمنی مانند ترمز، فرمان، نشتی سوخت، داغ‌شدن غیرعادی موتور یا هشدارهای خطر، از رانندگی خودداری کرده و به تعمیرکار متخصص مراجعه کنید.

## کلمات کلیدی پیشنهادی

خودرو، مکانیک، عیب‌یابی خودرو، صدای موتور، چراغ چک، هوش مصنوعی، تعمیر خودرو

## متن تغییرات نسخه 1.0.0

اولین انتشار مکانیک هوشمند؛ شامل عیب‌یابی اولیه با متن، عکس، صدا و ویدئو، مدیریت خودروها و سوابق بررسی.

## آیکون فروشگاه

یک PNG مربع 512×512 آماده کنید. طرح پیشنهادی: پس‌زمینه سرمه‌ای تیره، نمای روبه‌روی خودرو با آچار کوچک و درخشش آبی/فیروزه‌ای؛ بدون نوشته، لوگوی برند دیگر، حاشیه یا جزئیات ریز.

## اسکرین‌شات‌ها

حداقل 4 تصویر واقعی از نسخه Release تهیه کنید؛ بدون قاب موبایل یا متن تبلیغاتی خارج از UI:

1. صفحه خانه و چهار روش تشخیص.
2. فرم تشخیص متنی همراه انتخاب خودرو.
3. صفحه نتیجه با هشدار ایمنی و پیشنهادها.
4. صفحه خودروهای من یا تاریخچه تشخیص‌ها.
5. اختیاری: صفحه اعتبار که در نسخه اولیه عبارت «خرید اعتبار به‌زودی فعال می‌شود» را نشان می‌دهد.

## حریم خصوصی و مجوزها

در فرم‌های مایکت و سیاست حریم خصوصی، شفاف بنویسید:

- متن مشکل، مشخصات خودرو و فایل‌های انتخابیِ عکس/صدا/ویدئو برای تحلیل به سرور پردازش ارسال می‌شوند.
- دوربین فقط هنگام درخواست کاربر برای ثبت عکس یا ویدئو استفاده می‌شود.
- میکروفون فقط هنگام درخواست کاربر برای ضبط صدای موتور استفاده می‌شود.
- برنامه برای ساخت حساب کاربری نام، شماره تلفن یا رمز عبور درخواست نمی‌کند.
- داده‌های خودرو و سوابق تشخیص روی دستگاه ذخیره می‌شوند؛ اعتبار و تراکنش‌ها سمت سرور مدیریت می‌شوند.

پیش از ارسال برای بررسی، یک صفحهٔ سیاست حریم خصوصی عمومی بسازید و نشانی آن را در پنل مایکت وارد کنید.

## محصولات درون‌برنامه‌ای (برای فعال‌سازی بعدی)

این سه محصول را از نوع مصرف‌شدنی در پنل مایکت بسازید. شناسه‌ها باید دقیقاً همین باشند:

| شناسه محصول | عنوان فارسی | توضیح |
|---|---|---|
| `credit_20` | بسته ۲۰ اعتبار | برای انجام تحلیل‌های بیشتر در مکانیک هوشمند |
| `credit_50` | بسته ۵۰ اعتبار | بسته اقتصادی اعتبار برای تحلیل خودرو |
| `credit_150` | بسته ۱۵۰ اعتبار | بسته پرحجم اعتبار برای استفاده مداوم |

قیمت هر بسته را فقط در پنل مایکت تعیین کنید؛ اپ قیمت را از خود مایکت می‌خواند و نباید قیمت را داخل برنامه وارد کنید.

پس از ساخت محصولات، این دو مقدار لازم است تا خرید فعال شود:

1. `MYKET_IAB_PUBLIC_KEY` از پنل مایکت، برای GitHub Actions Secret.
2. `MYKET_ACCESS_TOKEN` برای Cloudflare Worker Secret، جهت تأیید سروری خرید.
